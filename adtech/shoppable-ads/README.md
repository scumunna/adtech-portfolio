## Technical Value Proposition
I architected this system to solve the **"Creative Wall"** in high-compliance retail. Instead of a 3-day manual design cycle, my Python-based engine generates these units in **under 2 hours** directly from client product feeds.

### **Key Technical Features:**
*   **Smart & Adaptive DCO:** Uses an `IntersectionObserver` to track dwell time and clicks, dynamically re-sorting the product tiles based on user behavior (DCO).
*   **Zero-Friction In-Unit Shopping:** Users can swipe through live inventory, view real-time pricing, and click "Buy Now" to deep-link directly to specific SKU pages.
*   **Automated Scaling:** The system automatically verifies image assets and generates IAB-compliant units in 4 major sizes (300x250, 336x280, 320x320, 300x600).
