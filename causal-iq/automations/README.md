# Causal IQ: Python-Driven Ad Ops Automation
**Replacing Manual Labor with Scalable Code**

At Causal IQ (~125 employees), I was the only operator writing code to solve workflow bottlenecks. I built a suite of Python/Pandas tools that were eventually adopted as the **official company-wide standard**.

---

## Technical Walkthroughs

### **1. Automated Optimization Engine**
*   **The Problem:** Manually adjusting bids and budgets for 100+ line items was a 4-hour daily task.
*   **The Solution:** A Python script that pulls API data, calculates performance against KPI thresholds, and generates an "Action List" for the trader.
*   **[Watch Video: Automated_Optimization.mp4](Automated_Optimization.mp4)**

### **2. Audience Insights Generator**
*   **The Problem:** Building post-campaign insight decks took 2 days of manual data pulling.
*   **The Solution:** Automated the generation of contextual, temporal, and demographic insight charts directly from raw DSP reports.
*   **[Watch Video: Audience_Insights.mp4](Audience_Insights.mp4)**

### **3. Dynamic Site List Management**
*   **The Problem:** Managing "Blacklists" and "Whitelists" across 10 different DSPs was inconsistent.
*   **The Solution:** A centralized tool to verify site transparency and auto-generate upload-ready CSVs for TTD and DV360.
*   **[Watch Video: Automated_Site_Lists.mp4](Automated_Site_Lists.mp4)**
